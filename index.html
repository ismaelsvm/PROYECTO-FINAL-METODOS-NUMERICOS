Protocolo del experimento

  1. Fija el routerTrabaja con la misma red y banda (2.4 o 5 GHz); anota si hay paredes.
  2. Marca las distanciasPor ejemplo: 1, 2, 3, 4, 5, 6, 7 y 8 m. Evita cambiar la orientación del dispositivo.
  3. Toma varias lecturasRegistra 3 a 5 valores de RSSI (dBm) por distancia con una herramienta que los muestre.
  4. Guarda y carga tu ExcelUna fila por lectura. Las repeticiones se promedian para el análisis.
Importante

SimuMath no puede medir la señal Wi-Fi directamente desde el navegador. El RSSI se captura en una aplicación o herramienta compatible del dispositivo.

¿Dónde están las matemáticas?

La regresión estima un modelo a partir de datos reales; Lagrange interpola valores intermedios; las diferencias finitas miden cambios locales y Newton-Raphson resuelve el umbral del modelo.
